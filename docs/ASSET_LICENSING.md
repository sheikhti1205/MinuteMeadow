# Asset licensing

Companion packs must include a license and enough attribution for someone who receives the pack on its own. The license must permit redistribution of every included image, font and sound. Permission to download an asset or use it in a portfolio does not necessarily allow redistribution in a pack.

List the original creator, source, license and any modifications. Include the full license text when the license requires it. Use separate attribution entries when a pack draws from sources with different terms.

For original art, identify the creator and use an approved license before submitting the pack. For third-party material, include a source link and record the exact terms that apply to that asset. Leave out assets when those terms cannot be established.

The app's code license and a pack's asset licenses are separate. A repository contribution does not change the terms attached to a third-party asset. No distribution license has been selected for the app.
