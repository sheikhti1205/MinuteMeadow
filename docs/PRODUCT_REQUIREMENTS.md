# Product requirements

MinuteMeadow is a portrait-first Android app for timing focus sessions and breaks. It must be useful offline without an account, a network catalogue or an installed companion.

Focus handles configurable sessions and breaks, supports pause and cancellation, and records session outcomes. Clock provides a stopwatch with laps and a countdown with saved presets. Insights uses saved sessions for daily, weekly and monthly summaries. Settings manages timer defaults, alerts, feedback, appearance, motion and local data.

Companion provides a library and curated catalogue. An empty catalogue is a supported state. Installed packs can be used offline and are loaded as data and assets. Installing or updating an invalid pack must leave existing content usable.

The first companion follows the non-art beta. Geometric fixtures exercise rendering, animation, movement, touch and ball play during development. Progression, payments, accounts and cloud sync are outside the first release.
