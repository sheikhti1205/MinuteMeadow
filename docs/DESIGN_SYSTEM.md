# Design system

The app uses warm paper and dark ink for large surfaces. Terracotta marks the primary action; olive identifies secondary selection. Light and dark themes use the same roles and follow the system setting by default.

Use the platform typeface for labels and paragraphs. Timer figures use tabular widths so the display does not shift as digits change. Keep the timer and its current action together and give completion or pause a text label.

The 16 logical pixel page inset gives the main content a consistent edge. Sprite pixels use a separate scale, chosen at render time from the asset size and available physical pixels.

Use pixel edges where they help identify shared controls or artwork. Preserve visible focus, readable text scaling and accessible touch targets. Leave companion space empty when no pack is installed.
