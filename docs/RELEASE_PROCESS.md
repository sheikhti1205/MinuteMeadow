# Releases

Use `MAJOR.MINOR.PATCH` for public versions. An incompatible public change increments the major version; a feature release increments the minor version; a fix to a released version increments the patch version. Increment the Android build number separately for distributed builds.

Before a release, confirm that the commit passes GitHub Actions and check the affected features on Android. Update the changelog with user-facing changes and known limitations. An Actions build is not a release. Publishing the repository, choosing its distribution license and distributing an APK require separate approval.
