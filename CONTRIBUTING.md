# Contributing

Companion Focus is in development. Contributions can cover Flutter code, Android behavior, documentation, accessibility, or companion-pack design. Discuss companion artwork before making a pack; the first pack follows the non-art beta.

- Keep pull requests focused on one change.
- Fix shared behavior in the module that owns it.
- Add a migration rather than editing a migration that has already been applied.
- Keep credentials, private data, and personal screenshots out of Git.
- Report security problems privately. See [SECURITY.md](SECURITY.md).

See [README.md](README.md) for the toolchain and [ROADMAP.md](ROADMAP.md) for planned work. A distribution license has not been selected.
